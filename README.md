# AAMRA Beauty & Wellness Centre

Luxury editorial website concept for AAMRA Beauty & Wellness Centre, Setia Alam.

## Included

- Responsive landing page
- Filterable treatment catalogue
- WhatsApp appointment booking form
- Founder section for Dr Azra Abd Aziz
- Location, hours and contact details
- GitHub Pages deployment workflow
- No framework or build step required

## Live site

https://shukritobi.github.io/AAMRA-Beauty-Wellness-Centre/

## Notes

Publicly listed promotional prices and opening information should be reconfirmed with AAMRA before production launch. The booking form sends a prefilled appointment request to AAMRA's public WhatsApp number.
